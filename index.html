Política de Privacidade

29 de março de 2026

1. Visão geral do produto

O Calendário Financeiro, ou simplesmente CalendarFin, é um aplicativo leve, fácil de usar e sem propagandas, criado para ajudar você a organizar suas finanças de forma prática, rápida e segura, nele seus dados não são coletados ou compartilhados com terceiros.

1.1 Coleta de dados

Este aplicativo não coleta, armazena ou transmite dados pessoais dos usuários para servidores externos ou terceiros.

1.2 Armazenamento de informações

As informações eventualmente inseridas pelo usuário no aplicativo são armazenadas exclusivamente no próprio dispositivo, sendo utilizadas apenas para o funcionamento das ferramentas disponibilizadas.

1.3 Compartilhamento de dados

Este aplicativo não compartilha, vende ou transfere dados do usuário para terceiros.

1.4 Responsabilidade do usuário

A inserção, gerenciamento e eventual exclusão das informações registradas no aplicativo são de inteira responsabilidade do usuário.

O usuário também é responsável pela segurança do dispositivo em que o aplicativo está instalado, incluindo o uso de senhas, bloqueios de tela ou outros mecanismos de proteção.

1.5 Segurança das informações

Embora o aplicativo não transmita dados para servidores externos, a proteção das informações armazenadas localmente depende das configurações de segurança adotadas pelo próprio usuário em seu dispositivo.

1.6 Alterações nesta política

Esta Política de Privacidade pode ser atualizada a qualquer momento para refletir melhorias ou alterações no aplicativo. Recomenda-se que o usuário consulte esta seção periodicamente.

7. Contato

Em caso de dúvidas, sugestões ou solicitações relacionadas a esta Política de Privacidade, o usuário poderá entrar em contato com o desenvolvedor por meio do canal disponibilizado no aplicativo.
