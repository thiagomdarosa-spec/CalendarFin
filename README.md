# CalendarFin - Site pronto para GitHub Pages

Arquivos principais:

- `index.html`: página inicial do site.
- `politica_de_privacidade.html`: página da Política de Privacidade.
- `editor_backup.html`: editor de Backup.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie estes arquivos para a raiz do repositório.
3. Acesse Settings > Pages.
4. Em Source, selecione Deploy from a branch.
5. Escolha a branch `main` e a pasta `/root`.
6. Salve e aguarde o GitHub gerar o link público.

Observação: o contador de acessos é local do navegador. Para contador global real, use um serviço externo ou backend.
